References and methodology

All of the data comes from public government sources. I started with the IRS list of tax-exempt organizations in Maryland. For each one, I pulled the most recent full Form 990 tax return (filed 2024–2026) from the IRS’s electronic filing records. From each return I took the leader’s name, title and pay from the officer pay section (Part VII), and the government grant total from the revenue section (Part VIII, line 1e), which lumps federal, state and local money together. To estimate state funding, I matched each organization’s name and ZIP code to the State of Maryland Grant and Loan dataset (FY2021–2025) on Maryland’s open data portal. For county funding, I did the same with Montgomery County’s open spending data (FY2023–2026), since no other Maryland county publishes comparable records. Finally, I divided the CEO’s total pay by each funding amount to get the percentages.
